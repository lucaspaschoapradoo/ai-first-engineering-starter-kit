# 10 — Plano de treinamento do time

## Público

Builders, Tech Leads e reviewers do fluxo.

## Módulo 1 — Modelo mental (60 min)

- Prompt-Driven vs Spec-Driven.
- Builder como decisor, IA como executor.
- MCP como Source of Truth.
- Evidence over claims.
- Change Impact Router.

Exercício: classificar 10 mudanças em Local / Behavioral / Structural.

## Módulo 2 — Da ideia ao Plan (90 min)

Executar:

- assess;
- corporate context;
- specify;
- clarify;
- plan;
- plan review.

Saída: feature pronta para task decomposition.

## Módulo 3 — Implementação low-code (120 min)

Builder não edita código.

Executar:

- tasks;
- analyze;
- implement;
- feedback de layout em linguagem natural;
- mudança comportamental;
- uma mudança estrutural para observar rewind controlado.

## Módulo 4 — Quality e Review (120 min)

Executar:

- run-quality;
- test strategy review;
- adversarial review;
- converge;
- compliance;
- PR;
- Codex review;
- rework;
- code-ready.

## Certificação interna

Builder conclui uma feature real ou sandbox com:

- 100% dos artefatos;
- MCP evidence;
- 0 Critical/High;
- review independente;
- readiness PASS;
- nenhuma edição manual de código durante o exercício.
